# Freedom

A modern luxury fintech web application built with **Next.js 14**, **React**, and pure high-performance CSS.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for Production

```bash
npm run build
npm start
```

## Deployment

Deploy with one click to **Vercel**:
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

The project uses Next.js App Router and is fully configured for zero-config deployment on Vercel, Netlify, or AWS Amplify.
